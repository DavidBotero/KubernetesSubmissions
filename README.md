# KubernetesSubmissions

Submissions for the DevOps with Kubernetes course.

Each exercise is a [release](https://github.com/DavidBotero/KubernetesSubmissions/releases) named after it, and the links below open the code as it was in that release. The Kubernetes configuration of the final project lives in a separate repository, [KubernetesSubmissions-config](https://github.com/DavidBotero/KubernetesSubmissions-config).
